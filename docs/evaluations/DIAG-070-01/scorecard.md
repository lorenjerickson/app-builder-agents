## Method and integrity

An independent Testing evaluator froze four public cases and sixteen binary checks
before subjects began. Fresh Coordinator and Retrospective subjects each answered two
independent fictional cases using the frozen candidate, without rubric or prior findings.
Only first outputs were scored; no coaching, repair or rerun followed. The evaluator
checked complete responses for contradictions and retained exact quotations and JSON
paths for all sixteen checks. Behavioral scoring accepted semantic equivalents.

Format completeness was assessed separately: required result envelopes and immediate
assignment fields were present. Later milestone skeletons await prerequisite evidence
and binding, and are not execution-ready assignments. This was not executable-schema
or runner-conformance certification. Shared-filesystem separation was instruction-based,
not an enforced security boundary.

All 14 candidate source files match the earlier evaluated snapshot. The original 97
historical evidence files remain unchanged. Raw cases, rubric, responses, assignments,
hashes and scoring remain in the external diagnostic record per contract §2a.
